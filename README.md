# 인터랙티브 프론트엔드 직무 발표

Vite + TypeScript + reveal.js로 만든 발표 첫 장입니다. 준비 화면 뒤에 진로 선택 인터랙션으로 발표자의 출발점을 소개하고, 서울과 분당구만 표시한 SVG 지도 위에 근무 이력을 순서대로 보여줍니다.

## 실행

Node.js 22.12 이상을 권장합니다. 최초 의존성 설치에 인터넷이 필요합니다.

```sh
npm ci
npm run dev
```

발표 현장에서는 미리 빌드한 결과를 로컬 서버로 실행합니다.

```sh
npm run build
npm run preview -- --port 4173
```

http://127.0.0.1:4173/ 에서 시작합니다. 지도, 폰트, JavaScript는 모두 로컬 파일입니다. 설치 및 빌드가 끝난 뒤에는 외부 인터넷 연결이 필요하지 않습니다. `dist/index.html`을 더블클릭하는 대신 로컬 서버를 사용하세요. 전체 진행 계획은 `PLAN.md`에서 확인할 수 있습니다.

## 조작

| 입력 | 동작 |
| --- | --- |
| 배터리가 검정색으로 바뀐 뒤 화면 클릭 / 오른쪽 방향키 / Space / Enter | 진로 선택 화면으로 이동 |
| 학사모 클릭 | 학점 3.26과 게임패드 물풍선 표시 후 두 진로 아이콘 등장 |
| 캐릭터를 플라스크로 드래그 | 연한 붉은 배경을 표시하고 선택 화면 유지 |
| 캐릭터를 컴퓨터로 드래그한 뒤 놓기 | 근무 연혁 지도 표시 |
| 지도 화면 클릭 / 오른쪽 방향키 / Space | 다음 근무 이력 |
| 왼쪽 방향키 / 이전 버튼 | 이전 근무 이력 |
| 처음부터 | 진로 선택 화면의 학사모 상태로 복귀 |
| F | reveal.js 전체 화면 |
| S | 발표자 노트 |

1. 2016.11–2019.07: 판교 · Exntu GPS 핀
2. 2019.08–2020.05: 강남 · KINX GPS 핀
3. 2020.05–현재: 분당구 영역 강조 · 프리랜서

준비 화면에는 녹색으로 충전되는 배터리와 진행률만 표시합니다. 약 2.2초의 충전 연출과 실제 자료 준비가 모두 끝나면 100% 검정색 배터리로 바뀝니다. 실제 준비가 늦으면 90%에서 대기합니다. 완료 문구와 별도 시작 버튼은 없으며, 화면 클릭이나 키 입력으로 진로 선택 화면을 엽니다. 준비 중 입력은 무시하고, 입력 한 번으로 여러 화면을 넘어가지는 않습니다. 모션 감소 설정에서는 충전 연출을 건너뜁니다.

진로 선택 화면에는 학사모를 쓴 3D 캐릭터가 중앙에 서 있습니다. 학사모를 누르면 학점 `3.26`과 게임패드가 각각 물풍선에 나타나고, 잠시 뒤 왼쪽 컴퓨터와 오른쪽 플라스크 아이콘이 표시됩니다. 캐릭터를 드래그하면 물풍선은 숨겨집니다. 플라스크와 겹치면 연한 붉은 배경, 컴퓨터와 겹치면 연한 연두색 배경을 표시합니다. 컴퓨터 위에서 놓으면 근무 연혁 지도로 이어지며, 나머지 위치에서 놓으면 캐릭터가 중앙으로 돌아옵니다. PDF와 발표자 노트 미리보기에서는 이 장면을 생략합니다.

캐릭터 화면에서 지도로 넘어가면 왼쪽의 지도가 기울어진 바닥 위치에서 약 1.1초 동안 떠오른 뒤 정면 위치에 자리 잡습니다. 지도 경계에만 얕은 입체감과 그림자를 줍니다. 모션 감소 설정에서는 등장 동작을 건너뛰며 PDF에는 그림자 없이 완성된 지도를 표시합니다.

판교·강남 핀은 끝점을 지도에 고정한 채 위로 솟아오르고 짧게 반동하며 자리 잡습니다. 분당 영역은 전체가 살짝 튀어나오며 색을 띠고, 얕은 입체감이 남습니다. 지도에는 ‘서울’과 ‘성남시 분당구’를 항상 표시합니다. 각 위치가 나타날 때 오른쪽에 회사명과 근무 기간을 크게 표시하고, 지역 설명은 발표자가 말로 전달합니다. 되돌아가면 해당 단계의 동작이 다시 재생되며, 모션 감소 설정과 PDF에서는 완성된 상태로 표시합니다.

클릭과 키보드는 reveal.js Fragment의 같은 상태를 사용합니다. 각 단계에서는 해당 핀 또는 분당구 강조와 오른쪽의 현재 이력 한 개만 보입니다. 이전 핀과 이력은 사라집니다. 하단 연혁, 연결선과 별도의 분당 GPS 핀은 없습니다. 초기화하면 오른쪽 정보도 숨기고 빈 지도로 돌아갑니다. 키를 길게 누른 반복 입력은 무시합니다. 마지막 단계는 현재 슬라이드에 머무르며, 추후 다음 슬라이드를 추가하면 다음 입력으로 넘어갑니다.

## PDF

http://127.0.0.1:4173/?print-pdf 를 Chrome에서 열고 인쇄합니다. 배경 그래픽을 켜고 머리글/바닥글을 끕니다. 로딩 및 조작 버튼은 제외하고 전체 이력을 한 페이지에 표시합니다. PDF에서는 왼쪽에 두 핀과 분당구 영역을 함께 보여주고, 오른쪽에 전체 이력 세 개를 세로로 나란히 출력합니다.

자동 출력도 가능합니다. Chrome이 설치되어 있어야 합니다.

```sh
npm run build
npm run pdf
```

결과: `output/pdf/career-history.pdf`

Chrome 대신 Playwright Chromium을 사용하려면:

```sh
npx playwright install chromium
PLAYWRIGHT_CHANNEL=chromium npm run pdf
```

## 검증

```sh
npm run build
npm test
```

실제 브라우저에서 클릭/키보드 혼용, 되돌리기, 초기화, 반복 키 입력, 분당 강조, 표시 지역, 외부 요청 차단, 모션 감소 및 인쇄 상태를 확인합니다. Playwright는 개발용 검증/PDF 출력에만 사용되며 발표 번들에는 포함되지 않습니다.

## 수정 위치

- `index.html`: 근무 이력과 발표자 노트
- `src/main.ts`: 준비 화면, 입력, Fragment 동기화
- `src/styles.css`: 화면 및 인쇄 스타일
- `scripts/generate-map.mjs`: 지역 필터, 대표 핀 위치, SVG 생성
- `SOURCES.md`: 지도와 글꼴 출처 및 라이선스

지도는 공개된 2018년 행정경계를 활용했습니다. 핀은 실제 사무실 주소가 아닌 근무 지역을 대표합니다.
